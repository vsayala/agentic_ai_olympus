# Olympus Databricks Retrieval Model Card

**Status:** Planned subsystem description; no production deployment asserted.

The subsystem provides governed ingestion, transformations, Unity Catalog assets, retrieval
adapters, and deployment definitions. Model and serving behavior depends on explicitly configured
Databricks services. Loki owns data provenance; Thor jointly reviews evidence consumed by agents.

No cloud readiness claim is valid without authenticated target validation, source approval,
least-privilege grants, protected deployment approval, and recorded operational evidence.
