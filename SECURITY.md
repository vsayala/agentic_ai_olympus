# Security Policy

## Reporting a Vulnerability

Report vulnerabilities through GitHub private vulnerability reporting for this repository. Do not
open a public issue containing exploit details, credentials, private source content, or customer
data. Include affected versions, reproduction steps, impact, and any suggested mitigation.

The maintainer will acknowledge a report, assess severity, coordinate remediation, and publish an
advisory when disclosure is appropriate. Never commit secrets; rotate any exposed credential before
removing it from history.

## Supported Versions

Security fixes target the current default branch until the project publishes a versioned support
policy. Production deployment remains subject to protected-environment approval.
